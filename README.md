# ОГЭ Химия

Бесплатный сайт для подготовки девятиклассников к ОГЭ по химии: теория по кодификатору, тренажёр по всем 24 заданиям, пробники с таймером, справочные таблицы и личный прогресс — без регистрации.

Технические требования и обоснование стека — в `TASK.md` (изначальное ТЗ).

## Стек

Astro 7 (статическая сборка) + React-острова + TypeScript (strict) + Tailwind CSS v4 + Content Collections (Zod) + KaTeX/mhchem (рендер формул на этапе сборки) + Pagefind (статический поиск). Бэкенда нет, прогресс — в localStorage браузера.

## Разработка

```bash
npm install
npm run dev        # http://localhost:4321
npm run check       # astro check (типы + Zod-схемы контента)
npm run build        # прод-сборка + генерация индекса Pagefind
npm run preview      # локальный просмотр собранной прод-версии
```

## Структура контента

- `src/content/theory/<topicId>/<slug>.mdx` — статьи теории. `topicId` берётся из `src/config/exam.ts` (`CODIFIER_TOPICS`).
- `src/content/tasks/<id>.json` — задания тренажёра/пробников. `id` в формате `"08-014"`.
- `src/content/zadaniya/<NN>.mdx` — разбор задания №N ОГЭ (`/zadaniya/N/`): алгоритм решения, типичные ошибки.
- `src/content/mocks/<slug>.json` — полные варианты пробников: `{ title, taskIds: [/* 24 id, по одному на каждый номер ОГЭ */] }`.

Все поля и ограничения — в `src/content.config.ts` (Zod-схемы). Сборка падает с понятной ошибкой, если контент не проходит валидацию.

Формулы пишутся через mhchem: `$\ce{H2SO4}$`, `$\ce{2H2 + O2 -> 2H2O}$` — рендерятся в HTML на этапе сборки, без JS на клиенте.

## Единый конфиг структуры экзамена

`src/config/exam.ts` — число заданий, баллы, шкала оценок, минуты, кодификатор. Перед каждым учебным годом сверять с демоверсией ФИПИ и менять только этот файл.

## Текущее состояние (MVP)

- Вся техническая платформа готова и работает: теория, тренажёр (фильтры по заданию/теме/сложности/ошибкам), пробники (таймер 180 мин, автосохранение, самопроверка части 2), справочник (таблица Менделеева, растворимость, ряд активности), личный прогресс (экспорт/импорт/сброс), поиск, SEO (sitemap, JSON-LD, OG-изображения на этапе сборки).
- Контент: 10 статей теории, разбор всех 24 заданий, 64 задания в тренажёре, 2 варианта пробников.
- Дальше — постоянное наполнение контентом до покрытия всего кодификатора и 400–500 заданий (см. ТЗ, раздел 12–14).

## Перед первым деплоем

1. Зарегистрировать домен и обновить `SITE_URL` в `astro.config.mjs`.
2. Задать `PUBLIC_YM_ID` (номер счётчика Яндекс.Метрики) как переменную окружения сборки.
3. Подключить домен к Яндекс.Вебмастеру и Google Search Console.
4. Проверить `robots.txt` и `sitemap-index.xml` на проде.
