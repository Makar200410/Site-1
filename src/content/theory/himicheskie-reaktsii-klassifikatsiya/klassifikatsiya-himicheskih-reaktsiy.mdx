## Четыре типа реакций по числу и составу веществ

<Callout kind="definition">
Классификация по числу и составу исходных веществ и продуктов реакции делит все химические реакции на четыре типа: соединения, разложения, замещения и обмена.
</Callout>

### Реакции соединения

Из двух (или более) веществ образуется одно новое сложное вещество:

$$\ce{A + B -> AB}$$

<Callout kind="example" title="Пример">
$\ce{2Mg + O2 -> 2MgO}$ — из простого вещества и простого вещества образуется одно сложное.

$\ce{CaO + CO2 -> CaCO3}$ — из двух сложных веществ образуется одно новое сложное.
</Callout>

### Реакции разложения

Из одного сложного вещества образуется два и более новых веществ:

$$\ce{AB -> A + B}$$

<Callout kind="example" title="Пример">
$\ce{CaCO3 ->[t] CaO + CO2 ^}$ — разложение карбоната кальция при нагревании.

$\ce{2H2O2 -> 2H2O + O2 ^}$ — разложение пероксида водорода.
</Callout>

### Реакции замещения

Атомы простого вещества замещают атомы одного из элементов в сложном веществе — участвует одно простое и одно сложное вещество, а в продуктах снова получается одно простое и одно сложное:

$$\ce{A + BC -> AC + B}$$

<Callout kind="example" title="Пример">
$\ce{Zn + 2HCl -> ZnCl2 + H2 ^}$ — цинк замещает водород в кислоте.

$\ce{Fe + CuSO4 -> FeSO4 + Cu}$ — железо вытесняет медь из раствора соли (по ряду активности металлов).
</Callout>

### Реакции обмена

Два сложных вещества обмениваются составными частями — реагируют два сложных вещества, и образуются два новых сложных вещества:

$$\ce{AB + CD -> AD + CB}$$

<Callout kind="example" title="Пример">
$\ce{AgNO3 + NaCl -> AgCl v + NaNO3}$ — обменная реакция с образованием осадка.

$\ce{HCl + NaOH -> NaCl + H2O}$ — реакция нейтрализации, тоже реакция обмена.
</Callout>

## Как быстро определить тип реакции

1. Сколько веществ вступает в реакцию и сколько получается?
2. Одно вещество на входе, несколько на выходе → **разложение**.
3. Несколько веществ на входе, одно на выходе → **соединение**.
4. На входе простое + сложное вещество, на выходе снова простое + сложное → **замещение**.
5. На входе два сложных вещества, на выходе два других сложных вещества → **обмен**.

<Callout kind="mistake">
Не путайте реакции замещения и обмена: в замещении обязательно участвует **простое** вещество, а в обмене реагируют **только сложные** вещества.
</Callout>

## Дополнительные признаки классификации

Помимо основного деления, реакции также классифицируют:

- по тепловому эффекту — экзотермические (с выделением теплоты) и эндотермические (с поглощением теплоты);
- по изменению степеней окисления — окислительно-восстановительные и реакции без изменения степеней окисления;
- по обратимости — обратимые и необратимые.
