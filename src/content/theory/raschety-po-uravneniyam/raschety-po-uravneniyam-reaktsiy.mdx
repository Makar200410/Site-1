## Ключевая идея

<Callout kind="important">
Коэффициенты в уравнении реакции показывают, в каком **мольном отношении** взаимодействуют вещества. Поэтому расчёты по уравнению реакции всегда идут через количество вещества (моль), а не напрямую через массу.
</Callout>

Основные формулы, которые понадобятся:

$$n = \frac{m}{M} \qquad n = \frac{V}{V_m} \qquad m = n \times M$$

где $n$ — количество вещества (моль), $m$ — масса (г), $M$ — молярная масса (г/моль), $V$ — объём газа (л), $V_m = 22{,}4$ л/моль — молярный объём газа при нормальных условиях.

## Алгоритм решения

1. Запишите уравнение реакции и расставьте коэффициенты.
2. Под формулами веществ, о которых идёт речь в задаче, подпишите известное и искомое количество вещества.
3. Переведите известную величину (массу или объём) в количество вещества.
4. Составьте пропорцию по коэффициентам уравнения и найдите искомое количество вещества.
5. Переведите найденное количество вещества в требуемую величину (массу, объём, число частиц).

<Callout kind="example" title="Пример: масса продукта реакции">
Какая масса оксида кальция образуется при разложении 50 г карбоната кальция?

$$\ce{CaCO3 ->[t] CaO + CO2 ^}$$

Молярная масса $\ce{CaCO3}$: $M = 100$ г/моль. Количество вещества:
$$n(\ce{CaCO3}) = \frac{50}{100} = 0{,}5 \text{ моль}$$

По уравнению 1 моль $\ce{CaCO3}$ даёт 1 моль $\ce{CaO}$, значит $n(\ce{CaO}) = 0{,}5$ моль.

Молярная масса $\ce{CaO}$: $M = 56$ г/моль.
$$m(\ce{CaO}) = 0{,}5 \times 56 = 28 \text{ г}$$
</Callout>

<Callout kind="example" title="Пример: объём газа по массе реагента">
Какой объём водорода (н.у.) выделится при растворении 13 г цинка в избытке соляной кислоты?

$$\ce{Zn + 2HCl -> ZnCl2 + H2 ^}$$

$M(\ce{Zn}) = 65$ г/моль, значит $n(\ce{Zn}) = 13 / 65 = 0{,}2$ моль.

По уравнению из 1 моль $\ce{Zn}$ получается 1 моль $\ce{H2}$, значит $n(\ce{H2}) = 0{,}2$ моль.

$$V(\ce{H2}) = 0{,}2 \times 22{,}4 = 4{,}48 \text{ л}$$
</Callout>

<Callout kind="mistake">
Если в задаче реагент дан «в избытке» или один из реагентов может быть взят не полностью, всегда рассчитывайте по тому веществу, о котором прямо известно количество (масса, объём) — а не по тому, что «в избытке».
</Callout>

## Если в задаче два реагента с известным количеством

Если известны количества обоих реагентов, сначала определите, какой из них в **недостатке** — именно по нему ведётся дальнейший расчёт:

1. Найдите количество вещества каждого реагента.
2. Разделите количество каждого на его коэффициент в уравнении.
3. Реагент с меньшим результатом — в недостатке, именно его количество определяет, сколько образуется продукта.
