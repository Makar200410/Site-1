## Что такое генетическая связь

<Callout kind="definition">
Генетическая связь между классами неорганических веществ — это связь между простым веществом и его производными сложными веществами, показывающая, что все они образованы одним и тем же химическим элементом и могут быть последовательно получены друг из друга.
</Callout>

На экзамене эта тема проверяется заданием на составление цепочки превращений: даны вещества A → B → C → D, нужно написать уравнения всех переходов.

## Типовая цепочка для металла

$$\ce{металл -> основный оксид -> основание -> соль}$$

<Callout kind="example" title="Пример: Ca -> CaO -> Ca(OH)2 -> CaCO3">

1) $\ce{2Ca + O2 -> 2CaO}$ — металл реагирует с кислородом, образуя основный оксид.

2) $\ce{CaO + H2O -> Ca(OH)2}$ — основный оксид реагирует с водой, образуя основание (щёлочь).

3) $\ce{Ca(OH)2 + CO2 -> CaCO3 v + H2O}$ — основание реагирует с кислотным оксидом, образуя соль.
</Callout>

## Типовая цепочка для неметалла

$$\ce{неметалл -> кислотный оксид -> кислота -> соль}$$

<Callout kind="example" title="Пример: S -> SO2 -> H2SO3 -> Na2SO3">

1) $\ce{S + O2 -> SO2}$ — неметалл реагирует с кислородом, образуя кислотный оксид.

2) $\ce{SO2 + H2O -> H2SO3}$ — кислотный оксид реагирует с водой, образуя кислоту.

3) $\ce{H2SO3 + 2NaOH -> Na2SO3 + 2H2O}$ — кислота реагирует со щёлочью, образуя соль.
</Callout>

## Другие частые переходы

- **соль → соль**, через реакцию обмена с образованием осадка: $\ce{CuSO4 + BaCl2 -> BaSO4 v + CuCl2}$;
- **соль → основание**, через реакцию со щёлочью: $\ce{FeCl3 + 3NaOH -> Fe(OH)3 v + 3NaCl}$;
- **соль → металл**, через вытеснение более активным металлом: $\ce{CuSO4 + Fe -> FeSO4 + Cu}$;
- **основание → оксид**, через разложение при нагревании: $\ce{Cu(OH)2 ->[t] CuO + H2O}$.

## Как решать задание на цепочку превращений

1. Определите класс каждого вещества в цепочке (простое вещество, оксид, основание, кислота, соль).
2. Для каждого перехода вспомните, какая реакция превращает один класс в следующий (см. типовые цепочки выше).
3. Составьте уравнение реакции, подберите коэффициенты и проверьте, что формулы веществ написаны верно.
4. Если переход не очевиден, попробуйте определить, какой реагент нужно **добавить**, чтобы получить нужный продукт — часто это вода, кислота, щёлочь или соль другого металла.

<Callout kind="mistake">
Не забывайте расставлять коэффициенты в уравнениях и проверять, что степень окисления элемента в цепочке либо не меняется (при обменных реакциях), либо меняется закономерно (при взаимодействии простого вещества с кислородом).
</Callout>
