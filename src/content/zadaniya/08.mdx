## Алгоритм решения

1. Определите, растворимое основание (щёлочь) дано в условии или нерастворимое — это влияет на набор возможных реакций.
2. Щёлочь реагирует с кислотами (нейтрализация), кислотными и амфотерными оксидами, растворами солей — если образуется осадок.
3. Нерастворимое основание реагирует только с кислотами; с кислотными оксидами и солями практически не реагирует.
4. Из пяти вариантов выберите два, которые дают реакцию по правилам выше.

## Типичная ошибка

Приписывают нерастворимому основанию (например, $\ce{Cu(OH)2}$, $\ce{Fe(OH)3}$) реакции, характерные только для щелочей — в первую очередь взаимодействие с кислотными оксидами, которое для нерастворимых оснований не идёт.
