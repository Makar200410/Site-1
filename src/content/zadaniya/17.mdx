## Алгоритм решения

1. Определите класс каждого из двух данных веществ и характерные для них ионы.
2. Переберите варианты реактивов и для каждого мысленно проверьте: даёт ли он видимый признак реакции хотя бы с одним из двух веществ?
3. Правильный реактив — тот, который реагирует **только с одним** из двух веществ с явным наблюдаемым эффектом (или даёт разные признаки с каждым из них), позволяя их различить.
4. Если реактив реагирует одинаково с обоими веществами (или ни с одним) — он не подходит для распознавания.

## Пример

Как различить растворы $\ce{NaCl}$ и $\ce{Na2CO3}$? Реактив — соляная кислота $\ce{HCl}$: с $\ce{Na2CO3}$ она даёт видимое выделение газа ($\ce{Na2CO3 + 2HCl -> 2NaCl + H2O + CO2 ^}$), а с $\ce{NaCl}$ видимых изменений нет — значит, кислота позволяет различить эти вещества.

## Типичная ошибка

Выбирают реактив, который реагирует с **обоими** веществами одинаковым образом (например, даёт осадок с обоими) — такой реактив не помогает их различить, ведь наблюдение будет одинаковым в обеих пробирках.
